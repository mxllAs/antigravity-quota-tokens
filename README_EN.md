## 📖 Overview

**Antigravity Quota & Token Monitor** is an open-source, non-intrusive extension specifically crafted for the **Google Antigravity IDE**.

Through a lightweight resident **Status Bar**, a powerful **QuickPick command palette**, and an activity bar **Modern Panoramic Webview Dashboard**, it provides holistic, real-time visibility into Antigravity's dual-tier rate limits, active context saturation, and 4-dimension AI compute token usage:

- **⚡ Dual-Tier Rate Limiting**: Real-time tracking of the actual 5-hour rolling limit (primary rate-limit trigger) and weekly quota health across both the **Gemini** and **Claude/GPT** unified model pools;
- **🧠 Context Capacity Gauge**: Automatic detection of the currently active model (e.g., `Gemini 3.8 Flash`) and context window (`1M` / `200k`), featuring a dedicated 4px dynamic capacity bar;
- **📊 4-Dimension Token Breakdown**: Granular insight into Fresh Input, Prompt Cache, Generated Output, and CoT Reasoning (Thinking) tokens;
- **🟩 GitHub 24-Week Heatmap**: Pixel-perfect replication of GitHub's canonical contribution calendar, tracking active coding days, current streak, peak consumption, and rolling totals;
- **📁 Historical Project Breakdown**: Collapsed by default for clean minimalism; expand any workspace to inspect session turns, context levels, and token totals;
- **🎨 Native Aesthetic Design**: High-contrast Quota Gauge & Lightning activity bar icon + global 6px sleek floating pill scrollbars.

## 🌟 Core Features

### 1. ⚡ Dual-Tier Rate Limiting (5-Hour Rolling + Weekly Quota)

Google Antigravity utilizes a dual-tier quota system. This extension interfaces directly with Antigravity's internal Connect-RPC service (`GetUserStatus` and `RetrieveUserQuotaSummary`):

- **5-Hour Rolling Limit (Primary Trigger)**: Most unexpected rate-limit pauses are caused by the 5-hour velocity limit rather than the weekly quota. The extension prominently displays this limit on the status bar and the main dashboard cards (e.g., `🟢 Gemini 63% (3h 3m) | 🟢 Claude/GPT 100%`) with live countdowns and colored status indicators (Green / Yellow / Red);
- **Weekly Health Limit**: Displayed subtly on card footers and status bar tooltips (e.g., `📅 Weekly Quota: 82% remaining · Resets in 2d 16h`), keeping you informed without visual clutter;
- **Dual Model Pool Grouping**:
  - **Gemini Pool**: Shared across Gemini 3.8 / 3.7 / 3.6 / Flash / Pro;
  - **Claude & GPT Pool**: Shared across Claude 3.5/3.7 Sonnet / Opus 4.6 and GPT-OSS.

---

### 2. 🧠 Active Session Intent & Context Saturation Gauge

- **Full-Width Session Title**: Extracts the official session intent/topic from SQLite snapshots (e.g., `"Project Analysis"`, `"Frontend Refactoring"`), giving the title 100% row width with zero awkward single-character truncations;
- **Model Context Detection**:
  - Identifies the exact model bound to the active session (`Gemini 3.8 Flash` with `1M` tokens, or `Claude 3.7 Sonnet` with `200k` tokens);
- **4px Dynamic Saturation Bar**:
  - `< 75%`: Tech Cyan/Blue (ample context headroom);
  - `75% ~ 90%`: Amber Alert (approaching saturation; consider starting a fresh session);
  - `> 90%`: Rose Red (critical threshold; potential memory summarization risk);
- **Status Bar Sync**: Quick indicator format `$(circuit-board) Context: 3.09w/1M (2.9%)`.

---

### 3. 📊 Today's 4-Dimension Token Breakdown

Token counts are categorized into four functional dimensions:

1. **Fresh Input**: Net-new prompt text, surrounding code slices, and instructions;
2. **Prompt Cache**: Tokens served directly from Gemini's prompt cache. The dashboard computes live **Cache Hit Rate (e.g., 95.6%)**, highlighting speedups and reduced quota consumption;
3. **Generated Output**: Tokens generated by the model in response;
4. **Thinking (CoT)**: Tokens consumed in internal reasoning/chain-of-thought channels;
5. **Intuitive Unit Formatting**: Formatted with clear units (e.g., `5731.6 万` / `57.3M`, `2.27 亿` / `227M`), with hover tooltips displaying exact digit counts.

---

### 4. 🟩 Pixel-Perfect GitHub 24-Week Contribution Heatmap

Matches GitHub's canonical contribution calendar layout:

- **Month Labels & Weekday Guides**: Dynamic top month headers (`May`, `Jun`, `Jul`...) and canonical weekday labels (`Mon`, `Wed`, `Fri`);
- **4-Level Green Intensity**: Automatically bucketed according to token consumption ranges, with the current day highlighted by a cyan breathing border;
- **Summary Metrics**:
  - **Active Days & Ratio**: e.g., `Active: 11 Days (7%)`;
  - **Peak Day**: e.g., `Peak: 09-03 · 173M`;
  - **Current Streak**: e.g., `Streak: 2 Days`;
  - **24-Week Rolling Total**: e.g., `24-Week Total: 614M`.

---

### 5. 📁 Historical Project Breakdown

- **Collapsed by Default**: The list starts in a tidy, collapsed state showing only project names (`📁 xxx`, `⭐ Current Project`) and total token usage;
- **On-Demand Drilldown**: Click any project header to smoothly expand all sessions within that workspace, inspecting session IDs, timestamps, turn counts, and per-session context usage;
- **Minimalist Design**: Free of redundant edit buttons, offering a clean and focused analytics dashboard.

### 6. 🎨 Native Aesthetics & Visual Polish

- **Custom Activity Bar Icon**: Replaced blurry dashed orbitals with a crisp, bold 2px geometric **Speedometer Gauge + High-Energy Lightning Bolt** (`assets/icon.svg`), using `currentColor` to adapt naturally to light and dark themes;

## 🔒 Architecture & Security

This extension adheres to rigorous security and non-intrusive standards:

1. **100% Local Execution, Zero Telemetry**:
   - Zero external network requests or third-party servers;
   - Never inspects, collects, or transmits your prompts, code, or personal account credentials;
2. **SQLite Read-Only Safety (`Zero Lock`)**:
   - Reads conversation stats using strict read-only connections (`PRAGMA query_only = ON;`) and WAL mode;
   - Never acquires exclusive write locks, and never mutates or corrupts Antigravity's internal database;
3. **Local Process Discovery**:
   - Discovers the local Antigravity Language Server process PID and extracts the ephemeral CSRF token;
   - All RPC requests communicate exclusively over the local loopback interface (`127.0.0.1`), requiring zero manual API key configuration.

## ⚙️ Settings

Press <kbd>Ctrl + ,</kbd> and search for `antigravityQuota`:

| Setting                               | Default | Description                                             |
| :------------------------------------ | :-----: | :------------------------------------------------------ |
| `antigravityQuota.showStatusBar`      | `true`  | Show or hide the resident status bar indicator          |
| `antigravityQuota.autoRefreshSeconds` |  `60`   | Background refresh interval in seconds (minimum 15s)    |
| `antigravityQuota.showGemini`         | `true`  | Show Gemini quota pool in status bar                    |
| `antigravityQuota.showClaude`         | `true`  | Show Claude/GPT quota pool in status bar                |
| `antigravityQuota.pythonPath`         |  `""`   | Custom Python interpreter path (auto-detected if empty) |

## 📦 Installation & Quick Start

### Method 1: Install from VSIX (Recommended)

1. Download the latest packaged release: `releases/antigravity-quota-tokens-1.0.16.vsix`;
2. In Antigravity IDE, press <kbd>Ctrl + Shift + X</kbd> to open the Extensions view;
3. Click the `...` menu on the top-right corner and select **"Install from VSIX..."**;
4. Select `releases/antigravity-quota-tokens-1.0.16.vsix`;
5. Click **"Reload Window"** when prompted.

### Method 2: Build from Source

```bash
# 1. Navigate to the extension folder
cd antigravity-quota-tokens

# 2. Validate syntax across all modules
npm test

# 3. Package into VSIX (automatically outputs to releases/ directory)
npm run package
```

The resulting package `antigravity-quota-tokens-x.x.x.vsix` will be generated in the `releases/` directory.

## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><b>Q1: Why do I get rate-limited when my weekly quota is still mostly available?</b></summary>
Antigravity enforces a strict <b>5-hour rolling velocity limit</b> in addition to the weekly quota. Sending heavy prompts or large codebases in a brief timeframe exhausts the 5-hour limit first. Check the 5h countdown on the status bar to see exactly when your allocation recovers.
</details>

<details>
<summary><b>Q2: Does this extension affect Antigravity's performance or cause editor lag?</b></summary>
No. All data retrieval runs asynchronously in non-blocking background routines. SQLite queries execute in read-only snapshot mode taking only a few milliseconds, ensuring zero editor stutter.
</details>

<details>
<summary><b>Q3: Why can't clicking a past session switch the right-hand AI chat panel?</b></summary>
Antigravity IDE's right-hand AI chat is an internal, proprietary component of the core VS Code workbench rather than an open webview. Currently, the IDE does not provide a public API for third-party extensions to programmatically switch active conversations. Use Antigravity's native shortcut <kbd>Ctrl + Shift + A</kbd> to open the conversation picker.
</details>
